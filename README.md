# Keychron Battery Monitor
Portable windows app that shows Keychron mouse battery status in system tray.

## ✅ Supported Devices
- Keychron M2 8K when using dongle
- May or may not work with other Keychron mice

## 📦 How to use
1. Download `keybat.exe` from [Releases](https://github.com/kolbasky/keychron-battery/releases/latest)
2. Run. No installation required
3. Optionally, copy or create link to `shell:startup` folder (`Win+R` -> `shell:startup`) to

> ⚠️ There are some [false-positives on virus-total](https://www.virustotal.com/gui/file/baae7bf634370b64ae6c013dde09f6efe026d0e0c212fe01523d2e5aed079c9a). Those pesky Bkav Pro, Elsatic and Trapmine are marking everything as a virus.

### 🔍 Debug Logging
Logging is disabled by default. To enable it, create an empty `keybat.log` file in the same folder as the executable.
